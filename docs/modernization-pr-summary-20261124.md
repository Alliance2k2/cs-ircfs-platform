# Refine CS-IRCFS interfaces and add scoped reporting evidence

The public site and dashboard had mobile overflow, inconsistent contrast and no
calendar-based receipt comparison. This change retains the existing public layout,
branding and working platform while adding scoped reporting comparisons, evidence
counts, searchable map alternatives, recorded boundary/crop-cluster presentation,
draft bilingual assistant controls and clearer incident/climate presentation.
The hero uses existing licensed local imagery; public activity copy distinguishes
demonstrations and received reports from operational pilot claims.

API responses now prevent private HTTP caching. Cooperative filtering follows the
existing staff and area rules. Dependency advisories are remediated through compatible
updates and verified router, Zod, Vitest and pytest upgrades. Existing uncommitted
assistant/ingestion work is preserved; generation and live providers remain disabled
in the isolated preview.

Validation: 458 backend tests passed (2 skips), 76 frontend tests passed, 34 browser
checks passed (1 optional model skip); typecheck, lint and production build passed.
Isolated PostgreSQL/PostGIS migrations and 36 model-table schema checks passed;
knowledge lifecycle passed, while the pgvector-specific check remains skipped.
The advisory audits report zero known npm vulnerabilities and zero findings across
56 installed Python packages. There are 49 before and 64 after captures, no after
overflow/runtime/error alerts, and 15 automated accessibility checks with no violations.
All 13 checked public links/anchors work.

The 64-case offline BM25 benchmark retains Recall@3/MRR 0.83 and extractive citation
accuracy 1.00. No generated-answer or semantic-retrieval quality is claimed. Semantic
benchmarking, native wording, approved agricultural sources/baselines, official
geography, carrier acceptance, configured live GIS/OAuth and hosted release verification
remain separate gates. The application entry bundle grew with security updates and
features; the large map chunk remains lazy. No production deployment is included.
